# Gateway overhead, 2026-10-28

Machine: 2 vCPU, Linux x86_64, Python 3.12.13. mockllm, the gateway and the load generator all ran on this one machine, so they competed for CPU. mockllm answered with a fixed 50 ms to first token and 32 tokens. Open-loop load, 15 s per row, after a 20-request warm-up, from a raw-socket client that opens a new connection per request. Overhead is the gateway's percentile minus the direct percentile: time to first content byte when streaming, total time otherwise.
